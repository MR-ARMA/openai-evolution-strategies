# 02_Theory_Zero_to_Hero — Mathematical & Intuitive Guide to Evolution Strategies

This directory provides a complete, zero-to-hero curriculum covering the mathematics, biological intuition, and systems engineering behind OpenAI's landmark paper **"Evolution Strategies as a Scalable Alternative to Reinforcement Learning"** (Salimans et al., 2017).

## Files in This Module

* **`index.html`**: The complete interactive textbook with vector SVG diagrams, neural network matrix visualizations, step-by-step LaTeX derivations (rendered via MathJax), and annotated Python code translations.
* **`styles.css`**: Modern dark-theme academic stylesheet powering the layout, mathematical proof cards, and matrix grids in `index.html`.

## How to View the Interactive Textbook

Clone the repository and open `index.html` directly in any web browser:

```bash
# On Linux
xdg-open 02_Theory_Zero_to_Hero/index.html

# On macOS
open 02_Theory_Zero_to_Hero/index.html
